## Featured work

### EEG Brain 3D

An application for exploring EEG recordings through signal traces, frequency-band filters, electrode visualization and cortical source estimates. Built with Python, MNE and a Three.js interface.

![EEG Brain 3D interface with signal traces and a sensor visualization](assets/eeg-overview.png)
